
# 🏛️ My Profile - Ismawati

Website profil pribadi yang dibuat sebagai bagian dari
tugas Praktikum P1 Pemrograman Platform.

Website ini menggunakan tema **Mitologi Yunani** dengan
perpaduan warna biru navy, emas, dan putih marmer.
Desain ini terinspirasi dari arsitektur dan ornamen
Yunani klasik, dengan tampilan yang sederhana,
elegan, dan responsif.

## 👩‍💻 Tentang Saya

Halo! Saya Ismawati, mahasiswa Teknik Informatika
yang sedang mempelajari pengembangan web.

Saya memiliki motivasi untuk terus berkembang dan
berkarya melalui teknologi. Website ini dibuat sebagai
media untuk memperkenalkan diri, menampilkan kemampuan,
serta mendokumentasikan proyek dan proses belajar saya.

## ✨ Fitur Website

Website profil ini memiliki beberapa bagian utama:

1. **Home**  
   Halaman utama yang menampilkan nama, foto profil,
   dan informasi singkat tentang saya.

2. **About**  
   Berisi perkenalan diri dan motivasi hidup.

3. **Tech Stack**  
   Menampilkan teknologi dan tools yang sedang
   saya pelajari.

4. **Projects**  
   Menampilkan proyek yang pernah saya kerjakan,
   salah satunya SIPERPUS (Sistem Informasi Perpustakaan).

5. **GitHub Contributions**  
   Menampilkan informasi mengenai riwayat perubahan
   atau commit pada repositori.

6. **Education**  
   Berisi informasi riwayat pendidikan.

7. **Personal Identity**  
   Menampilkan informasi identitas pribadi.

Setiap menu menggunakan navigasi interaktif sehingga
pengunjung dapat melihat bagian yang dipilih tanpa
menampilkan seluruh bagian sekaligus.

## 🎨 Tema dan Desain

Tema yang digunakan adalah **Mitologi Yunani**.

Elemen desain yang digunakan:
- Biru navy sebagai warna utama.
- Emas sebagai warna aksen.
- Putih marmer sebagai warna latar.
- Ornamen yang terinspirasi dari budaya Yunani.
- Tipografi bergaya klasik untuk judul.
- Tata letak responsif untuk desktop dan perangkat mobile.

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3

- Git
- GitHub

## 📁 Struktur Folder

```text
My-Profile/
├── index.html
├── Foto Profile.jpeg
└── README.md
```

Keterangan:
- `index.html` : file utama yang berisi struktur,
  tampilan, dan interaksi website.
- `Foto Profile.jpeg` : foto profil yang digunakan pada website.
- `README.md` : dokumentasi repositori.

## 🚀 Cara Menjalankan Website

1. Clone repositori ini:

   ```bash
   git clone https://github.com/008-Isma/My-Profile.git
   ```

2. Masuk ke folder proyek:

   ```bash
   cd My-Profile
   ```

3. Buka file `index.html` menggunakan browser.

Website juga dapat dijalankan menggunakan ekstensi
Live Server pada Visual Studio Code.
